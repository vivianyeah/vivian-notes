## Defensive-read pattern (recurring lesson from P-MR-88/89 + P-MR-90)

External data (broker API, trades_log JSON, state files) may contain explicit `None`, missing keys, or wrong types. Default-arg `.get('field', default)` does NOT cover explicit `None`. Always:

```python
# WRONG — crashes if value is None
p.get('current_price', 0)

# RIGHT — falls back through None, missing key, falsy value
(p.get('current_price') or p.get('entry_price') or 0)
```

**Comma-formatted numbers** (P-MR-186): scan stdout emits `$91,853.97`, `$93,388.11`, etc. Always parse with comma-aware groups and `replace(',','')`:

```python
# WRONG — drops leading digits on comma-formatted totals
m = re.search(r'持倉市值:\s*\$([\d.]+)', stdout)
total = float(m.group(1))  # "853.97" instead of "91853.97" → off by $90k

# RIGHT — capture comma-formatted + strip commas
m = re.search(r'持倉市值:\s*\$([\d,.]+)', stdout)
total = float(m.group(1).replace(',', ''))  # 91853.97 ✓
```

Apply both patterns to any place scan.py reads API positions, computes sums, or filters dicts.

```python

from fifo_pnl import fifo_open_positions

# 1. Per-line API view parser (P-MR-168) — catches 5% 止蝕 prefix that re.findall misses
api_positions = []
seen = set()
for line in stdout.splitlines():
    if not re.search(r'qty=[\d.]+\s+現價=\$[\d.]+', line): continue
    mm = re.search(r'(?:🟢|🔴|🟡)\s+(.+?)\s+([A-Z][A-Z0-9.]*)\s+qty=([\d.]+)\s+現價=\$([\d.]+)', line)
    if mm and mm.group(2) not in seen:
        api_positions.append({'symbol':mm.group(2), 'qty':float(mm.group(3)), 'price':float(mm.group(4))})
        seen.add(mm.group(2))
print(f"API view: {len(api_positions)} positions")
rebuild_n = int(re.search(r'\[rebuild\] API 持倉 (\d+) 隻', stdout).group(1))
assert len(api_positions) == rebuild_n, f"⚠️ P-MR-168 prefix regex dropped {rebuild_n - len(api_positions)} positions"

# 2. ⭐5 fallback (P-MR-169) — non-held Stage 2 candidates need this for current_price
prices = {p['symbol']:p['price'] for p in api_positions}
for line in stdout.splitlines():
    mm = re.search(r'⭐5\s+([A-Z][A-Z0-9.]*)\s+\$([\d.]+)', line)
    if mm: prices[mm.group(1)] = float(mm.group(2))

# 3. FIFO view (true current state from trades_log)
open_lots = fifo_open_positions(log)
print(f"FIFO view: {len(open_lots)} positions")

# 4. Diff → likely broker reconcile lag if diff > 0 and >1 cron old
api_syms = {p['symbol'] for p in api_positions}
fifo_syms = set(open_lots)
print(f"only_in_api: {api_syms - fifo_syms}")   # lag shell positions
print(f"only_in_fifo: {fifo_syms - api_syms}") # not yet broker-confirmed
```
